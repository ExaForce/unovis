import { XYWrapper, XYWrapperWithInput, axis } from '../wrappers/xy-wrapper'

export const scatterProps = (n = 10, colored = false) => ({
  name: "Scatter",
  data: generateScatterDataRecords(n, colored),
  x: d => d.x,
  y: d => d.y,
});

export const gaussian = (mean, sd) => mean + sd * (Math.random() + Math.random() + Math.random() - 1.5) * 2
export const generateSwarmData = (n, groups = 1) => Array(n).fill(0).map((_, i) => ({
  group: i % groups,
  value: Math.round(4 * gaussian(5 + 2 * (i % groups), 1 + 0.5 * (i % groups))) / 4,
}))

export const swarmGroups = ['Group A', 'Group B', 'Group C']
export const groupSwarmProps = () => ({
  name: "Scatter",
  data: generateSwarmData(240, swarmGroups.length),
  x: d => d.group,
  y: d => d.value,
  size: 8,
  spreadAxis: 'x',
  containerProps: { xDomain: [-0.5, swarmGroups.length - 0.5] },
  components: [axis('x', { tickValues: [0, 1, 2], tickFormat: i => swarmGroups[i] }), axis('y')],
})

## Basic Configuration
The _Scatter_ component has been designed to work together with _XYContainer_. The minimal _Scatter_ configuration looks like:
<XYWrapper {...scatterProps()} y={d => d.y} showContext="full"/>

## Point Appearance
### Custom Shape
You can change the point's symbol using the `symbol` attribute, which accepts a `SymbolType` or a corresponding `string`
(`'circle'`, `'cross'`, `'diamond'`, `'square'`, `'star'`, `'triangle'`, `'wye'` ) or a function (executed per data point) that returns either of them.
<XYWrapper {...scatterProps(15)} shape={'wye'}/>

### Custom Color
You can provide _Scatter_ with a single `color` hex value or a `color` accessor function.
<XYWrapper {...scatterProps(15)} color={'#DA348F'}/>

### Stroke Color
You can also set a stroke color for your points by providing a `strokeColor` hex value or a `strokeColor` accessor function.
<XYWrapper {...scatterProps(15)} color="none" strokeColor={'#DA348F'}/>

### Stroke Width
If you want to change the stroke width, you can use the `strokeWidth` property, which accepts a constant value or an accessor function.
<XYWrapper {...scatterProps(15)} color="none" strokeColor={'#DA348F'} strokeWidth={5}/>

### Size and Size Range
You can use the `size` property to set the point size (i.e. point diameter if `shape` is set to `SymbolType.Circle`) in pixels
by providing a constant value or an accessor function, e.g.: `d => d.size`.

<XYWrapper {...scatterProps()} size={50} />

_Scatter's_ `sizeRange` attribute represents a range of numbers for a point's size. When `sizeRange` is set, the `size`
property will be treated as relative and all the points will be rescaled according to the provided range.

In tha case if you provide a constant value to `size`, every resulting size value will be the median of `sizeRange`.
Fox example, if `sizeRange` is set to `[10,50]`, that will make the default size equal to 30px (or `(min + max)/2`).
<XYWrapper {...scatterProps()} size={() => 10 * Math.random()} sizeRange={[10, 50]}/>

## Spreading Points
When many points have close values, they pile up on top of each other. Set `spreadAxis` to `'x'` or `'y'` to move
the points along that axis just enough to stop the overlap, while their position on the other axis stays exact. This
turns the scatter into a beeswarm, where the shape of the swarm shows how the values are distributed.

The points are placed one by one, largest first, each as close to its own position as it can get. So the larger
points end up in the middle of the swarm, and the smaller ones fill in around them.

In this example every point has the same `y`, and `spreadAxis` is set to `'y'`. A symmetric `yDomain` puts the line
of points in the middle of the chart, so the swarm can grow to both sides of it.
<XYWrapper
  name="Scatter"
  data={generateSwarmData(200)}
  x={d => d.value}
  y={0}
  size={8}
  spreadAxis="y"
  containerProps={{ yDomain: [-1, 1] }}
  components={[axis('x')]}
/>

### Limiting the Spread
By default the points can spread across the whole plot area. When you have several swarms along the same axis, for
example one per category, limit how far the points can move with `spreadMax`. It's set in the domain units of
`spreadAxis` and applies to the edge of the point. With categories placed at `0, 1, 2…`, a `spreadMax` of `0.45`
keeps every swarm within 45% of the distance to the next category, leaving a gap between the neighbouring swarms.
Above `0.5` the swarms would reach into each other.

For categories, also set the domain to `[-0.5, n - 0.5]`, where `n` is the number of categories. Every category then
gets a slot one unit wide, the edge ones included, and the categories stay in place whatever `spreadMax` is. Without
it, _Scatter_ takes the room the first and the last swarm need at the edges of the chart, so the categories move
closer to the edges as `spreadMax` goes down.

If a swarm doesn't fit, all the points shrink by the same factor until every swarm fits, so the sizes stay
comparable across the whole chart. The padding between the points shrinks with them. The points can shrink until the
smallest of them is 1px across; if even that's not enough, they are pushed into their limits and may overlap.
<XYWrapperWithInput {...groupSwarmProps()} property="spreadMax" inputType="range" inputProps={{ min: 0.05, max: 0.5, step: 0.05 }} defaultValue={0.45}/>

### Padding
`spreadPadding` sets the gap between the neighbouring points in pixels. It's `1` by default.
<XYWrapperWithInput {...groupSwarmProps()} spreadMax={0.45} property="spreadPadding" inputType="range" inputProps={{ min: 0, max: 4, step: 0.5 }} defaultValue={1}/>

Note that _Crosshair_ follows the values of the points, not their positions in the swarm.

## Point Labels
You can also place labels on _Scatter's_ points by passing a string accessor function to the `label` property.
<XYWrapper {...scatterProps(15, true)} size={20} label={d => d.label}/>

### Label Color
You can also configure a custom color for your labels by providing the `labelColor` attribute with a color accessor method or string.
Note that setting this property overrides `labelTextBrightnessRatio`.

<XYWrapper {...scatterProps(15, true)} size={20} label={d => d.label} labelColor={'red'}/>

### Label Position
You can change a point's label position with the `labelPosition` property, which accepts a  _Position_ or _Position_ accessor
function. Supported values are `Position.Center`, `Position.Bottom` (default), `Position.Left`, `Position.Right` and `Position.Top`.
Labels with `Position.Center` take the largest font size at which the text, measured in the label's font, fits inside the point.

<XYWrapperWithInput {...scatterProps(15, true)} hiddenProps={{ size: d => d.size, label: d => d.label}} property='labelPosition' inputType="select" options={['bottom', 'center', 'left', 'right', 'top']}/>

### Label Position Lists
`labelPosition` also takes a list of positions to try in order. Every label goes to the first position where it
doesn't overlap other points and labels and stays within the chart, and `Position.Center` is taken only when the label
can be at least as large inside the point as outside of it. A label that fits nowhere is hidden until you hover over its
point. Compare it with the [Overlapping Labels](#overlapping-labels) example below, where every label is either at the
bottom or hidden:
<XYWrapper {...scatterProps(45, true)} size={10} color={d => d.color} label={d => `Point ${d.label}`} labelPosition={['bottom', 'top', 'right', 'left']}/>

When the swarms of [spread points](#spreading-points) stand vertically, a list like `['right', 'left']` lets the
labels use both sides of every swarm.
<XYWrapper {...groupSwarmProps()} data={generateSwarmData(60, swarmGroups.length)} spreadMax={0.45} label={d => d.value} labelPosition={['right', 'left']}/>

The list only takes effect with `labelHideOverlapping`; without it, every label takes the first position.

### Label Text Brightness Ratio
By default, labels with `Position.Center` will be assigned a color based on the point's shade with the `labelTextBrightnessRatio` property.
It accepts any value between `0` and `1` (inclusive).

The default setting `0.65` creates darker text on light backgrounds and light text on dark backgrounds.
See how the contrast differs in the following examples, when we assign more extreme values to the `labelTextBrightnessRatio` property:
<XYWrapperWithInput {...scatterProps(10, true)} size={20} color={d => d.color} label={d => d.label} labelPosition="center" property="labelTextBrightnessRatio" inputType="range" inputProps={{ min: 0.5, max: 0.7, step: 0.01}} defaultValue={0.65}/>

### Overlapping Labels
When there're overlapping labels, _Scatter_ will hide some of them to avoid cluttering. You can see hidden labels by hobvering over the points.
If you want to disable hiding overlapping labels, you can set the `labelHideOverlapping` property to `false`.
<XYWrapperWithInput {...scatterProps(45, true)} size={10} color={d => d.color} label={d => `Point ${d.label}`} property="labelHideOverlapping" inputType="checkbox" defaultValue={true}/>

### Overlapping Points
A chart with far more points than horizontal pixels draws most of its markers on top of one another,
where they can be neither seen nor hovered. Setting `cullOverlappingPoints` to `true` keeps only the
point that would be painted on top of each pixel, which cuts the number of rendered elements several
times over on dense charts.

```ts
const cullOverlappingPoints = true
```

It is off by default because it isn't pixel-perfect: the skipped points sit at sub-pixel offsets rather
than exactly behind the one that's kept, so a dense cloud comes out slightly thinner, and they no longer
fire pointer events. Use it when individual markers can't be told apart anyway. It has no effect together with
`spreadAxis`: spread points don't overlap, so there is nothing to skip.

## Custom Cursor
_Scatter_ also allows to set a [custom](https://developer.mozilla.org/en-US/docs/Web/CSS/cursor) `cursor` when hovering
over a point by providing a `cursor` accessor function.

## CSS Variables
The _Scatter_ component supports additional styling via CSS variables that you can define for your visualization container. For example:

<CodeBlock language="css" title="styles.css">
{`.custom-vis {
  --vis-scatter-fill-opacity: 0.5;
  --vis-scatter-stroke-width: 1;
  --vis-scatter-hover-stroke-width: 2;
  --vis-scatter-point-label-text-color-dark: darkblue;
}`
}
</CodeBlock>

<XYWrapper {...scatterProps(50)} showAxes={true} height={250} excludeTabs label={d => d.label} size={20} labelTextBrightnessRatio={0.5} className="custom-scatter"/>

The labels outside the points take `--vis-scatter-point-label-text-color`, and until it's set,
`--vis-scatter-point-label-text-color-dark`: the darker of the two colors central labels pick from to contrast with the point.
